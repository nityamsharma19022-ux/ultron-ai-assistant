# ULTRON feature status

Every feature, with honest status. IMPLEMENTED = built and covered by
automated tests in the sandbox. VERIFIED = also seen working end to end
against the real running services (how is noted). TESTING = waiting for a
check on your Windows PC or iQOO phone. Nothing here claims device testing
that didn't happen.

_Last updated: 2026-11-10._
